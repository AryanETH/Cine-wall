# CineWall glasses

anaglyph-glasses.glb is "3D Red Cyan Anaglyph Glasses" by Valentin Cotta (@vcotta), downloaded through Sketchfab's authorized Original format download on 28 October 2026. 7,516 bytes, 62 triangles, no textures or external buffers. The original GLB bytes are unchanged. Runtime geometry is scaled, centred, mirrored in X for the red-left view and shaded in the custom canvas renderer. No extra GPU context, model-viewer or Three.js dependency.

Creator and license attribution appears alongside the glasses purchase link when 3D view is active. Attribution does not imply the creator endorses CineWall or the linked merchant. The initial temporary original model was replaced after the user completed sign-in.

The small button/purchase icons now use the earlier original CineWall box-based model, anaglyph-icon.gltf (11,160 bytes, 156 triangles). The downloaded GLB is used only for the centre activation animation. Its original bytes remain unchanged.

Coplanar triangles are grouped into a single canvas fill with consistent winding. This removes the dark antialiasing seams between individual triangle fills without drawing wireframe lines or changing the original GLB file.
