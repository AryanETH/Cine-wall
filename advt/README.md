# Advertising Dashboard

## Quick Access

**Password:** `9669`

## Start Server with Ads Enabled

```bash
npm run start:ads
```

Then open: http://localhost:4173/advt

## Features

- Upload ad videos (MP4, H.264, max 25 MiB)
- Configure ad slots (Skippable, Standard, Bumper)
- Enable/disable advertising system
- Set advertiser contact form
